## 最直观的 3 个问题
1. **相对路径配置破坏常驻插件启动**：`.kore-local.yaml` 的 `state_dir/run_dir` 是相对路径，supervisor 设 `cmd.Dir` 后 exec 与 socket 均按嵌套 cwd 解析，site enable 直接 502；配置加载时应固化为绝对路径（本次仅用符号链接绕过，属环境 workaround）。
2. **无 nginx 时 site 直接回滚 + 把“跳过”显示成“失败”**：`nginx` 不存在被当作 `-t` 失败，vhost 不落盘；即使 test_skipped，页面仍显示红色「nginx -t 未通过 / 未加载」，用户无法区分“未测”和“测挂”。
3. **cron 读取权限错误直出 500 与原始报错**：`crontab -l` 权限不足时接口 500，页面直接渲染 `fopen: 权限不够: cron: storage I/O error`，且产生 1 条 console error；应降级为空列表 + 可操作提示。

补充：概览「常驻插件 2」与监控「常驻插件数 3/3」口径/时点不一致；lazy 的 cron 在已装插件页显示黄点 stopped、监控页却 ready，易误读为故障。
