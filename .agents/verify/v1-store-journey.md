## 3. 商店路径 vs 离线路径差异（对用户是隐形的坑）

| 维度 | 商店路径（点安装） | 离线路径（`kored install --package`） |
| --- | --- | --- |
| 服务状态 | **运行中直接装**，无需停 kored | **必须先停 serve**（state.db 独占，运行中撞锁 exit 3） |
| 包来源 | 索引 `download_url` 自动下载，验签 + sha256 | 用户自己准备 tar.gz，CLI 校验 |
| 进度反馈 | 卡片状态 + SSE 阶段（快网只看到终态） | 终端一行 `installed <id> <version>` |
| 启用 | 装完 `desired=disabled`，**要手动启用** | 同左（也要手动启用） |
| 升级 | 商店「升级到 vX」按钮，保留 desired、自动重启插件 | 停服后重装/覆盖，感知不到「旧版本保留」 |
| 卸载 | 不支持（只有停用） | 无卸载命令，目录需手删 |

**最容易被误解的两点**：①「安装成功」≠「能用」，还要去已装插件页点启用；②「升级成功」不等于旧版清掉，`data/plugins/<id>/<old>` 会留下。
