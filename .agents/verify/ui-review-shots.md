## 我独立看到的 3 个界面问题（供 lead 对照）

1. **移动端顶部导航是“藏起来的横滑条”**：390 宽下 nav 内容 494px、可视 390px，滚动条被 CSS 隐藏；默认只看到「概览/软件商店/已装插件」和「监控」（右边被切约 10px），「设置」完全在屏外，没有渐隐/箭头/更多提示。用户不横滑就找不到设置入口。证据：review-10（默认态）、review-11（滚到末端才露出监控/设置）。
2. **商店的安装模型与“商店”定位错位**：整个商店只有顶部一个全局「本地包路径（install 必填 package_path）」输入框，21 张卡片各自的「安装」按钮共用它；目录数据里的 `download_url` 没有用于自动下载。用户点任意卡片的安装前，得先自己把某个 tar.gz 粘进顶部输入框，否则必 400；卡片上看不出这次装的是哪个包。证据：review-03/10 文案与 store.js 的 install body。
3. **监控页空数据呈现像坏图且高度重复**：CPU/内存/磁盘/负载 4 张卡全部「—」，每张都重复同一段「待补端点：GET /api/v1/system/metrics（契约建议…）」；内存卡的预算条只画出一段虚线和孤立竖线，视觉上像图表加载失败。应合并为一条全局“端点未实现”提示，或把 4 张空卡收起。证据：review-06。
