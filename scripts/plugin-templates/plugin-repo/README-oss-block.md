本仓库是 **kore** 的 `{{NAME}}`（id `{{ID}}`），独立仓库、独立版本线、独立 CI：GitHub Actions 只手动触发（`workflow_dispatch`），按版本 tag 自动触发在 Gitea Actions（`.gitea/workflows/ci.yml`，push `v*` + 手动）。内核与协议见 [kore](https://github.com/kore-pl/kore)。

- **许可**：MIT（inbound = outbound，不要求 CLA）；提交用 `git commit -s` 签 DCO。

- **安全**：[SECURITY.md](SECURITY.md)——漏洞不要开公开 issue。
- **行为准则**：[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)。
- **兼容性**：`protocol: {{PROTOCOL}}` · `requires_kore: {{REQUIRES_KORE}}` · `lifecycle: {{LIFECYCLE}}` · 深度等级 `{{DEPTH}}`。
- **验证方式**：本地 `make check` 优先（GitHub CI 只手动触发，Gitea CI 按版本 tag 触发；发布前 `make dist` 连跑两次核对 sha 一致）。
- **发布产物**：`make dist` → `dist/{{ID}}-{{VERSION}}.tar.gz` + `.sha256`（位级可复现，连跑两次 sha 相同）。
