# DESIGN-SYSTEM — 视觉层次与组件规范（v1）

> 一句话：每页**先给一个焦点**，配置**默认只露一层**，状态**用图形不用句子**。
> 本规范把 [FRONTEND.md](./FRONTEND.md) §5 的尺度表升级为可执行分档，把 [USABILITY.md](./USABILITY.md) 原则 1「预设优先」落成唯一控件规格。审计证据与逐页问题见 [DESIGN-AUDIT.md](./DESIGN-AUDIT.md)。

## 0. 适用面

| 项 | 内容 |
| --- | --- |
| 读者 | implementer（照此写）、verifier（照此验） |
| 作用 | 字号/颜色/间距/卡片/控件/空态/状态/图示/层叠/操作位置的**判定规则** |
| 不作用 | 不改令牌名与对比度基线（归 FRONTEND §5）；不定义业务字段 |

## C1 五档字号

| 层级 | 字号 | 字重 | 用途 | 例子 |
| --- | --- | --- | --- | --- |
| Display | 32px | 600 | 单页核心数字，**每页 ≤4 个** | `24 核`、`61.3 GiB`、`9.9%` |
| H1 | 20px | 600 | 页面标题 | 监控、日志 |
| H2 | 15px | 600 | 区块/卡片标题 | 磁盘、网络、健康检查 |
| Body | 13px | 400 | 正文、表格、说明 | 进程名、路径、解释句 |
| Caption | 12px | 400 | 单位、时间、辅助 | `3 分钟前`、`MiB`、列名 |

- 现状：`--kore-font-12/13/14/16/20`，**缺 Display 与 H2 档**；实测 12px 占全部 `font-size` 的 71%（132/187），20px 仅 5 处 → 名义五档、实际「12px 一统」。
- 新增令牌 `--kore-font-32`、`--kore-font-15`，**同检查点回写 FRONTEND §5 尺度表**（G-06）。
- 迁移规则：12px 只保留给 Caption（列名/单位/时间）；正文一律 13px；14px 仅用于输入框与按钮；每页至少 1 个 Display。
- 禁止裸写字号（现存 9 处 `11px` 违规）。

## C2 三档文字色

| 令牌（实为 `--kore-text-1`） | 值 | 用途 | 禁用于 |
| --- | --- | --- | --- |
| 主 | `#E6EDF3` | 正文、数值、可点文本 | 说明句 |
| 次 | `#9DA7B3` | 解释、label、二级信息 | 主数值 |
| 弱 | `#7D8590` | 时间戳、单位、占位提示 | 可点文本 |

- 三档令牌已存在且对比度达标（15.2:1 / 7.0:1 / 4.6:1）。真问题不是缺色，而是**字号与色阶错配**：label 与 value 同为 13px、仅靠灰度分层，扫读靠颜色不靠尺寸 → 值必须比 label 至少高一档字号（Body+ 或 Display）。
- 同一卡片内不得出现超过 3 种文字色。

## C3 间距节奏

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `space-1/2/3/4` | 4/8/12/16 | 行内间距、控件内边距、卡片内边距(16) |
| `space-6` | 24 | **区块/卡片之间** |
| `space-8`（新增） | 32 | 页面级分组（首屏大区块之间） |

- 硬规则：区块间距 24、卡片内边距 16、正文行高 1.5、表格行高 32。
- 现状：token 使用分布 183/146/103/55/10 —— 24px（区块节奏）仅 10 次，`gap:2px` 11 次（非 4 基线值）。**禁止 6/10/18/2 等非基线值**。
- 判别：两个卡片「挨着看不出分组」就说明该用 24 而不是 16。

## C4 卡片结构（所有卡片一致）

```
┌ 标题（H2 + 可选图标）            [可选：右侧 ≤1 主操作 + ⋯]
│  主体：Display / 表格 / 图表（三选一，不混排长文）
└ 可选脚注（Caption）：口径、时间、来源
```

- 每卡 ≤1 个 Display；主体内**连续纯文字 ≤3 行**，超出必须转表格或图示。
- 卡内不得再套卡；同屏容器级区块 ≤2（FRONTEND 红线 1）。
- 标题右侧只放 1 个主操作，其余进 `⋯`；危险操作永远不在卡片标题栏。

## C5 预设 + 自定义统一控件（通用规则，非个例）

```
[预设] 每天 3 点 │ 每 6 小时 │ 每周日 2 点 │ 自定义 ▾      ← 默认态，只有这一层
                                       ↓ 点「自定义」
[cron 输入框]  [常用示例：0 3 * * * / 0 */6 * * *]  [验证：✓ 有效]
```

规则（违反即返工）：

1. 预设是**默认且唯一**可见态；用户不点「自定义」，**永不出现**表达式/路径/端口/PEM/阈值输入框。
2. 预设 ≤4 个，单击即生效（≤1 次点击），**当前选中态必须有视觉高亮**。
3. 自定义展开后预设仍可见，可一键切回预设；切回不丢已填值。
4. 自定义区必须给 2–3 个常用示例 + **就地验证结果**（✓/✗ + 一句为什么），不要提交后才报错。
5. 高级参数默认全折叠；折叠/展开不触发额外请求、不重置已填值；必须有「恢复默认」。
6. **所有需要配置的地方都套此模式**（备份定时、SSL 续期、清理策略、告警阈值、权限、端口、阈值…）。

**判定标准**（何时必须有第二层）：

| 必须有第二层 | 不需要第二层 |
| --- | --- |
| 有高级参数（glob / cron / PEM / 端口 / 阈值 / 路径列表） | 纯展示区块 |
| 有多种策略可选（压缩算法、密钥类型、重定向策略） | 单一确定值（版本号、状态） |
| 有表达式类输入（cron、模式匹配、正则） | 布尔开关（启用/停用） |
| 有「默认值不合用」的专业场景 | 搜索/筛选框 |

- **参考实现**：`web/backups.js:14` 的 `PRESETS`（每天 3 点 / 每 6 小时 / 每周日 2 点 / 自定义）+ 人话回显。全站照此推广，不要另造第三套。
- 现状：**12 处缺第二层**，逐项见 [DESIGN-AUDIT.md](./DESIGN-AUDIT.md) §6。

## C6 空态四件套

| 元素 | 规格 |
| --- | --- |
| 图标 | 32px、`--kore-text-3`、语义图标（非 emoji） |
| 标题 | H2：「还没有站点」——说清"没有什么" |
| 解释 | Body 一句：为什么空 + 空的后果 |
| 主按钮 | ≤3 字：「新建站点」。**禁止隐藏主操作** |

- 禁止「一行灰字」（现状 13 处空态：**0 处有图标**，四件套合规 0/13）。
- 该页确无可执行动作时，按钮换成「查看文档」链接——仍要有出口。
- 表格空态、卡片空态、整页空态同规格，不得三级三样。

## C7 状态表达

| 状态 | 视觉 | 文本 |
| --- | --- | --- |
| 成功 | 绿点/绿勾 | `运行中`、`通过` |
| 警告 | 黄点/黄三角 | `偏高`、`需注意` |
| 危险 | 红点/红叉 | `失败`、`已停用`（仅故障语境） |
| 中性 | 灰点 | `空闲`、`未检测` |

- 必须**图形 + 文本双通道**（FRONTEND 红线 9）；禁止纯文字、纯色、emoji 表状态。
- `chip()` 现被复制在 10 个模块（logs/sites/monitor/monitor-cards/backups/db/redis/ssl/integrity/firewall）→ 收敛为 1 个组件，新增状态只加映射。
- **危险色通胀**：`--kore-danger` 只给「不可逆 / 故障」，不得给常规「停用插件」「删除文件」这类可逆/常规操作当默认色（商店每卡红「停用」即违规）。

## C8 图示优先（展示层也用图形）

**原则**：能用图形表达的不用文字；文字只保留无法图形化的具体值。

| 信息类型 | 现在（文字） | 改成（图示） | 无障碍兜底 |
| --- | --- | --- | --- |
| 状态 | 「状态：运行中」「● 正常 健康检查」 | 色点/图标 + 极简标签 + tooltip | `aria-label` |
| 容量/占用 | 「已用 29.1%」 | 进度条 / 环形 | `role=progressbar` |
| 趋势 | 单个 CPU 数字 | sparkline（内联 SVG） | 折叠 `<details>` 表格 |
| 关系 | 「依赖：A、B」 | 连线 / 树 | 文本列表 |
| 流程 | 「当前阶段：extract」 | 步骤条（第 n / 共 m） | `<ol>` |
| 分布 | 进程 Top10 表格 | 横向条形 | 表格 |
| 数量对比 | 「已装 21，可升级 1」 | 数字 + 小条 | 文本 |

**状态展示规范**（本条为 C7 的展示细则）：

- 形态固定为 `[色点/图标] + [极简标签]`；状态值（正常/异常/运行中）由**颜色**表达，**detail 进 tooltip**。
- tooltip 双端：PC `:hover` + `:focus-within`；手机 `click` 切换（`max-width:639px` 或 `pointer:coarse`），触控目标 ≥44px；`aria-describedby` 兜底；零第三方库；z-index 走 C9（提示 50）。
- **判断标准**：① 该图示化——状态值、布尔、计数、比例、趋势、关系、流程阶段、分布；② 必须保留文字——路径、IP/端口、版本号、错误原文、sha256、用户输入的标识符、需精确比对的数字；③ 边界——「是否健康」这类一眼要判断的结论必须**图形 + 极简标签并列**，不能只留图形靠悬停才知道。

| 改造前 | 改造后 |
| --- | --- |
| `● 正常 健康检查` `● 正常 系统信息` | `[✓ 健康]` `[ⓘ 系统]`（绿点在内，名词保留，详情进 tooltip） |
| 终端 `已连接`（绿字） | `● 已连接` |
| 商店 `已安装 ✅`（emoji） | 内联 SVG 勾 + `已安装` |
| 插件 `状态：运行中` | `● 运行中` |
| 磁盘 `已用 29.1%` | 进度条 + 右侧 `29%` |
| 防火墙三格 `不可读` | `⊘ 需 root` + tooltip 说明怎么提权 |

## C9 层叠与角标

| 层 | z-index | 元素 |
| --- | --- | --- |
| 0 | 内容 / 表格 | 常规流 |
| 10 | 卡片 | `.panel` |
| 20 | 悬浮按钮 | FAB / 回到顶部 |
| 30 | 抽屉 | 移动端导航抽屉 |
| 40 | 弹窗 | Dialog / 确认框 |
| 50 | 提示 | tooltip / toast |
| 60 | 角标 | 计数徽标（永远最上） |

- **角标必须溢出父容器可见**：承载角标的父级 `overflow` 必须 `visible`；需要裁剪的容器不得直接当角标父级。
- **横向滚动行容器是陷阱**：`overflow-x:auto` 会让 `overflow-y` 计算为 `auto`，整行变成裁剪容器。把角标挂到滚动容器**之外**的 `position:relative` 壳，或给容器 `padding-top:6px` 留出溢出空间。
- 统一角标：`top:-6px; right:-6px; min-width:16px; height:16px; z-index:60`，2px 同底色描边避免与图标粘连。
- 禁止在 `overflow:hidden` 的 `.panel` / `.plugin-ui-card` 内使用负偏移角标。
- 父级有 `transform` / `filter` / `opacity<1` 会新建层叠上下文，角标 z-index 只在父级内比较——跨层级请用固定层而非提高 z-index。

**已确认裁剪点**（详见审计 §4）：`style.css:1392` 移动端 `.kore-topbar .conn{overflow-x:auto}` 裁掉 `shell.js:345` 的 `top:-6px` 红点。

## C10 操作位置分级

| 级别 | 位置 | 允许放 | 判据 |
| --- | --- | --- | --- |
| 一级 | 顶栏 / 主导航 / 首屏 | 高频、安全、可逆（搜索、刷新、切换视图） | 误触后果 ≈ 0 |
| 二级 | 页面内主按钮 / 行内操作 | 业务主流程（新建、保存、启动、编辑） | 误触可撤回或仅影响单条 |
| 三级 | 弹层 / 设置子项 / 折叠区 | 危险、低频、不可逆（删除、退出、重置、覆盖基线） | 误触造成数据或会话不可恢复 |

判定式：**误触后果（可逆/不可逆）× 使用频率（高/低）**；两者冲突以「误触后果」为准——不可逆一律下沉三级。

- 退出登录只能有一个入口，且必须在三级（设置 → 账户）。现状顶栏与设置页**各一个**（`web/app.js:351` + `web/settings.js:109`）→ 违规。
- 删除/停用/恢复/重建基线：行内可保留（FRONTEND 红线 10），但必须二次确认 + 危险色只给不可逆项。
- 提权（root）操作：默认禁用 + 说明「为什么不可用 + 怎么获得」，不得静默灰掉。

## 验收

任一条不满足，UI 不得声明完成（G-28 双端截图须能证明）：

1. 每页首屏有 ≥1 个 Display 焦点，且 5 档字号各自语义正确；
2. 所有配置项都能在**不展开自定义**的情况下一次提交成功；
3. 空态有图标 + 标题 + 解释 + 按钮（0 处一行灰字）；
4. 状态全部「图形 + 文本」，`danger` 未用于可逆操作；
5. 移动端无角标被裁、无横向溢出；PC hover / 手机 tap 均能看全 tooltip；
6. 一级页面无不可逆操作。
