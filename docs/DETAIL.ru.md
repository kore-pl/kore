# Kore

Kore — тонкое ядро, которое только планирует: оно задаёт правила жизненного цикла плагинов, проверки прав, маршрутизации сообщений и изоляции ресурсов, а реальные функции предоставляют 18–22 независимых репозитория плагинов. По умолчанию нет аккаунтов, онлайн-проверок и телеметрии; конфигурация — открытый текст. Первая выпущенная версия — 0.1.1 (0.1.0 никогда не выпускалась).

## Что делает проект

- **Тонкое планирование**: никакой операционной логики в ядре; ноль импортов плагинов в `internal/core`. Плагины работают отдельными процессами, запускаются по требованию и завершаются в простое.
- **Пять опор**: форма (один резидентный процесс, ноль таймеров по умолчанию), архитектура (только правила), ресурсы (жёсткий предел ≤16 МиБ в простое), открытость (ноль исходящих клиентов, ноль телеметрии), опыт (первый экран ≤300 КиБ gzip).
- **Мультирепозиторий**: здесь находятся ядро, публичный SDK `pkg/pluginapi`, фронтенд и центр Collaborate; плагины живут в `kore-plugin-<id>` и зависят только от SDK.
- **Уровни платформ**: Linux — Tier A с полными функциями; Windows 10 1809+ / macOS 12+ — Tier B с ослабленной изоляцией; ниже минимума — выход с кодом 6.
- **Ноль телеметрии**: нет аккаунтов, онлайн-проверок и скрытой отчётности; конфигурация — открытый текст.

## Быстрый старт

```bash
make docs-check    # проверка доков: метаданные, ссылки, заглушки, строки
make help          # все цели make и статус M0

# С M1: собрать bin/kored и запустить оболочку
make build && ./bin/kored
```

Для начала прочитайте `QUICKSTART.md` в корне (сборка → минимальная конфигурация → запуск → первый вход). Для работы с несколькими репозиториями используйте `go work init kore kore-plugin-echo`; не фиксируйте `go.work`.

## Безопасность и границы

Уязвимости сообщайте через [SECURITY.md](../SECURITY.md) (подтверждение в течение 72 часов / согласованное раскрытие через 90 дней); не создавайте публичные issue. Проект безопасности (модель угроз, аутентификация, CSRF, проверка полномочий, изоляция) — в [docs/SECURITY.md](SECURITY.md). Скрытый исходящий трафик, недекларируемая отчётность и обход прав считаются высокорисковыми — сообщайте по электронной почте.

## Частые вопросы

**В: Нужен ли аккаунт?**
Нет. Нет аккаунтов, онлайн-проверок и скрытой телеметрии; конфигурация хранится в открытом тексте, который можно читать и менять.

**В: Где находятся плагины?**
Каждый плагин живёт в собственном репозитории `kore-plugin-<id>`. Здесь только ядро и публичный SDK.

**В: С какого документа начать?**
Начните с `QUICKSTART.md` (от сборки до первого входа), затем используйте указатель «что я хочу сделать» в `docs/README.md`.
